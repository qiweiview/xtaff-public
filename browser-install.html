Install the Xtaff Browser local host

The local host connects the Xtaff Browser extension to an AI assistant using MCP. The extension and host run on your computer. Your assistant may send data it receives to its configured model provider.

Get Xtaff Browser from the Chrome Web Store

View @xtaff/browser-mcp on npm

Requires desktop Chrome 125+ and Node.js 22+. macOS has been tested; Linux and Windows have not yet been verified.

Setup

  1. Install the Xtaff Browser extension from the Chrome Web Store.
  2. Install and register the local host in a terminal: 
    npm install --global @xtaff/browser-mcp
xtaff-browser-host
    Run the second command again after moving or replacing Node, the global npm directory, or the package.
  3. Configure your MCP client to run xtaff-browser-mcp. Find its absolute path using which xtaff-browser-mcp on macOS/Linux or where xtaff-browser-mcp on Windows.
  4. Restart the MCP client. Ask it to use Xtaff Browser; approve the requested website in the extension popup. Tabs must be in the Xtaff group.

For Codex, add the following to ~/.codex/config.toml, replacing the path:

[mcp_servers.xtaff-browser]
command = "/absolute/path/to/xtaff-browser-mcp"

For Claude Code, run claude mcp add --scope user --transport stdio xtaff-browser -- /absolute/path/to/xtaff-browser-mcp.

To uninstall, run xtaff-browser-host --uninstall followed by npm uninstall --global @xtaff/browser-mcp. See the privacy policy for data handling and controls.

中文安装说明

Xtaff Browser 通过本机宿主连接浏览器和 MCP 助手。需要桌面版 Chrome 125+ 与 Node.js 22+。macOS 已验证；Linux 和 Windows 尚未验证。

  1. 从 Chrome 网上应用店安装 Xtaff Browser 扩展。
  2. 运行上方 npm 安装和注册命令；Node、npm 全局目录或安装包位置改变后需重新注册。
  3. 在 MCP 客户端中配置 xtaff-browser-mcp 的绝对路径；Codex 和 Claude Code 示例见上方。
  4. 重启 MCP 客户端，要求助手使用 Xtaff Browser，并在扩展弹窗批准需要访问的网站。

卸载时先运行 xtaff-browser-host --uninstall，再运行 npm uninstall --global @xtaff/browser-mcp。助手可能将扩展返回的数据发送给其配置的模型服务；详见隐私政策。

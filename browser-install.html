Install the Xtaff Browser local host

The local host connects the Xtaff Browser extension to an AI assistant using MCP. The extension and host run on your computer. Your assistant may send data it receives to its configured model provider.

Download local host 0.1.0 (ZIP)

SHA-256: 3831cc658d8899d00908671174d7b6c909acaf8ff7fda1b3e5d115cd739475a9

Requires desktop Chrome 125+ and Node.js 22+. macOS has been tested; Linux and Windows have not yet been verified. Keep the extracted folder in a permanent location.

Setup

  1. Install the Xtaff Browser extension from the Chrome Web Store.
  2. Extract the ZIP and open a terminal in the extracted xtaff-browser-host folder. Run node scripts/install.mjs --store. If the folder or Node installation moves, run it again.
  3. Configure your MCP client to run Node with the absolute path to dist/index.js in that folder. Find the Node executable with node -p 'process.execPath'. The downloaded README includes an example for Claude Code.
  4. Restart the MCP client. Ask it to use Xtaff Browser; approve the requested website in the extension popup. Tabs must be in the Xtaff group.

For Codex, add the following to ~/.codex/config.toml, replacing both paths:

[mcp_servers.xtaff-browser]
command = "/absolute/path/to/node"
args = ["/absolute/path/to/xtaff-browser-host/dist/index.js"]

To uninstall, run node scripts/install.mjs --store --uninstall from the extracted folder, then remove it. See the privacy policy for data handling and controls.

中文安装说明

Xtaff Browser 通过本机宿主连接浏览器和 MCP 助手。需要桌面版 Chrome 125+ 与 Node.js 22+。macOS 已验证；Linux 和 Windows 尚未验证。下载本机宿主并解压到固定位置。

  1. 从 Chrome 网上应用店安装 Xtaff Browser 扩展。
  2. 在解压后的 xtaff-browser-host 目录打开终端，运行 node scripts/install.mjs --store。目录或 Node 位置改变后需重新运行。
  3. 在 MCP 客户端中将 Node 可执行文件设为命令，将该目录下 dist/index.js 的绝对路径设为参数；Codex 配置示例见上方，Claude Code 示例见压缩包中的 README。
  4. 重启 MCP 客户端，要求助手使用 Xtaff Browser，并在扩展弹窗批准需要访问的网站。

卸载时，在解压目录运行 node scripts/install.mjs --store --uninstall，然后删除该目录。助手可能将扩展返回的数据发送给其配置的模型服务；详见隐私政策。
